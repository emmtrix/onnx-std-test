== Terms and definitions

// Metanorma opens this clause with "For the purposes of this document, the
// following terms and definitions apply." itself, so this sentence adds only
// what that one does not say.
The terms and definitions given in <<onnx-part-1>> also apply.

[[vector-outcome]]
=== outcome

result of applying one <<test-vector-t,test vector>> to an implementation, being one of
_pass_, _fail_, _unsupported_ or _error_

[[test-vector-t]]
=== test vector

model, together with input values, expected output values and the tolerance
against which they are compared
