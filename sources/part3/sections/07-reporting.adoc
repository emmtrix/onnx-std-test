== Reporting

=== General

A conformance report records the outcome of every vector selected under
Clause 5.

=== Content

A conformance report SHALL state:

* the identity and version of the implementation;
* the version of this package used;
* the conformance class and profile claimed;
* for each vector, its identifier and its <<vector-outcome,outcome>>;
* for each vector with the outcome _fail_, the achieved deviation.

=== Relationship to the conformance statement

The conformance statement required by Annex A of <<onnx-part-1>> SHALL cite the
report produced under this clause.
