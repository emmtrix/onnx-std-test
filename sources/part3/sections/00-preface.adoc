[.preface]
== Introduction

A conformance requirement that cannot be checked is not a requirement. Part 1
states what an implementation must do; this part supplies the vectors that
decide whether it did.

It is a separate part because it tracks Part 2: a vector exists for an operator
at an operator set version, so the package moves on the operator sets' cadence
rather than the core's.

It is also the part most likely to be embedded in implementations, as test
suites usually are, which may argue for a licence different from that of the
prose. That question is open; see Annex C of Part 1.
