== Type system

=== General

Every value in an ONNX <<graph>> has a type. Types are either tensor types,
sequence types, map types or optional types.

=== Shapes

A shape is an ordered sequence of dimensions. Each dimension is one of:

* a non-negative integer, denoting a fixed extent;
* a symbolic name, denoting an extent that is equal wherever the same name
  occurs within one <<graph>>;
* unknown.

A tensor with a shape of length zero is a scalar. A dimension of extent zero is
permitted; a tensor having such a dimension contains no elements.

=== Composite types

==== Sequence

A sequence is an ordered, homogeneous collection of values of a single type.

==== Map

A map is an unordered association of keys of an integral or string element type
to values of a single type.

==== Optional

An optional value either holds a value of its element type or is absent.
