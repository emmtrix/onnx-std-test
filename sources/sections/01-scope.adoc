== Scope

This document specifies the Open Neural Network Exchange (ONNX) format: an
interchange representation for computational graphs used in machine learning,
together with the type system, the serialization format and the semantics of
the standard operator sets.

This document specifies:

* the data types and shapes that values in an ONNX model may take;
* the structure of an ONNX model, graph, node, tensor and attribute;
* the evaluation semantics of an ONNX graph;
* the binary serialization of an ONNX model;
* the versioning and compatibility rules governing operator sets;
* the conformance classes that an implementation may claim.

This document does not specify:

* the numerical accuracy required of an implementation beyond the tolerances
  stated in <<conformance>>;
* the internal representation, scheduling or optimization strategy of a
  runtime;
* training procedures, optimizers or loss functions, except where they are
  expressed as operators within a graph;
* hardware requirements, performance characteristics or resource limits;
* the ONNX reference implementation, its API or its source distribution.
